# 我的马克：AI 时代的文档排版利器

![WordMarker Logo](./images/app-icon.png)

WordMarker能够将AI生成的文本转换为Word格式，支持DeepSeek、豆包、千问、Kimi、ChatGPT、Gemini、Claude等国内外AI模型。是你在公文写作、论文写作、课程作业等场景的好助手。

![alt text](image.png)

直接复制AI生成的文本到Word中，并不会保留原有的格式，尤其是数学公式、表格、代码等内容，会变成一堆混乱的字符。如下图所示：

![alt text](image-1.png)

左边是Kimi AI生成的文本，直接复制到右边的Word中，标题样式和加粗样式并没有保留，数学公式也变成一堆混乱的字符。

但是在使用WordMarker转换后，标题样式、加粗样式、表格和数学公式都能完美保留，如下图所示：

![alt text](image-1-1.png)

WordMarker支持两种转换方式：直接复制和转换为文件。

对于短文本，比如和AI的某一次对话或者某个数学公式，萝卜哥推荐直接复制的方式，操作简单快捷。

![alt text](image-3.png)

对于长文本，比如论文、报告等，萝卜哥推荐转换为文件的方式。因为长文本直接复制可能会导致系统剪贴板奔溃，转换为文件的方式可以避免这个问题。

![alt text](image-4.png)
